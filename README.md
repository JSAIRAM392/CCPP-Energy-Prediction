
# Combined Cycle Power Plant Energy Output Prediction

## Project Description
This project predicts the net hourly electrical power output (PE) of a Combined Cycle Power Plant using Machine Learning regression algorithms.

## Dataset
Combined Cycle Power Plant Dataset containing 9,568 observations.

## Input Features
- Ambient Temperature (AT)
- Exhaust Vacuum (V)
- Ambient Pressure (AP)
- Relative Humidity (RH)

## Target Variable
- Electrical Power Output (PE)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Project Objectives
- Analyze power plant data.
- Apply regression algorithms.
- Compare model performance.
- Predict electrical power output.
